### ¿Para qué se usa?

- Revisar código antiguo

- Analizar errores pasados

```bash
git checkout <hash_del_commit>
```

## 🧠 ¿Qué es `git reset`?

`git reset` permite **mover la rama actual a un commit anterior**, modificando el historial del repositorio.

👉 Se usa para **deshacer commits** o **reorganizar cambios**.

## ⚙️ Sintaxis básica

```bash
git reset [opción] <commit>

```

---

## 🔹 Tipos de `git reset`

### 🔸 `-soft`

```bash
git reset --soft a1b2c3d

```

- Mueve la rama
- Mantiene los cambios en _staging_
- Útil para rehacer commits

---

### 🔸 `-mixed` (por defecto)

```bash
git reset a1b2c3d

```

- Mueve la rama
- Mantiene los cambios sin confirmar
- Saca los archivos de _staging_

---

### 🔸 `-hard` ⚠️

```bash
git reset --hard a1b2c3d

```

- Mueve la rama
- Borra todos los cambios
- El proyecto queda igual al commit indicado

⚠️ **Peligroso**: los cambios se pierden definitivamente.

---

## ✅ Buenas prácticas

- Usar `-soft` para corregir commits
- Evitar `-hard` en repositorios compartidos
- No usar `git reset` sobre commits ya enviados (`push`)

# `git checkout` vs `git reset`

## 🧠 Idea clave

- **`git checkout`**: sirve para _explorar el pasado_ sin cambiar la historia.
- **`git reset`**: sirve para _deshacer cambios_ y modificar la historia del repositorio.

# 🚀 ¿Qué es GitHub?

**GitHub** es una plataforma en la nube que permite **alojar repositorios Git**, colaborar en proyectos de software y gestionar el desarrollo de código de forma organizada.

👉 Importante:

- **Git** es la herramienta de control de versiones.
- **GitHub** es el lugar donde se almacenan y comparten los repositorios Git.

> 🔑 Git es el motor, GitHub es el garaje donde trabajan todos juntos.

---

## 🧑‍💻 ¿Para qué se utiliza GitHub en equipos de desarrollo profesionales?

- 👥 **Trabajo colaborativo** entre desarrolladores
- 🕵️ **Seguimiento de cambios** y autores
- 🌱 **Desarrollo en paralelo** usando ramas
  En entornos profesionales, GitHub se usa para:
- 🔁 **Revisión de código** (Pull Requests)

> En la industria, **todo proyecto serio tiene un repositorio en GitHub**.

## 🆕 Cómo crear un repositorio en GitHub

1. Inicia sesión en GitHub
2. Haz clic en **New repository**
3. Completa:
   - **Repository name**
   - Descripción (opcional pero recomendada)
   - Público o privado
4. Haz clic en **Create repository**

✅ Listo, tu repositorio ya existe en GitHub.

## 🔗 Cómo conectar un repositorio de GitHub con Git (repositorio local)

### Opción 1: Repositorio local existente

```bash
git init
git add .
git commit -m "Primer commit"
git branch -M main
git remote add origin git@github.com:usuario/repositorio.git
git push -u origin main

```

### Opción 2: Clonar un repositorio existente

```bash
git clone git@github.com:usuario/repositorio.git

```

Esto crea:

- La carpeta del proyecto
- La conexión automática con GitHub

---

## ⬆️ Push y ⬇️ Pull: conceptos clave

### 🔼 `git push`

Envía los cambios locales a GitHub.

```bash
git push origin main
```

> “Subo mis cambios al repositorio remoto”

---

### 🔽 `git pull`

Trae los cambios de GitHub a tu computador.

```bash
git pull origin main

```

> “Actualizo mi copia local con lo último del equipo”

---

## 📥 Cómo clonar un repositorio

Clonar significa **copiar un repositorio remoto a tu máquina**.

```bash
git clone git@github.com:usuario/repositorio.git

```

Se usa cuando:

- Empiezas a trabajar en un proyecto existente
- Colaboras en un repositorio de otra persona

## 🔐 Configurar llaves SSH (recomendado)

Las llaves SSH permiten conectarse a GitHub **sin escribir usuario y contraseña cada vez**.

### 1️⃣ Crear la llave SSH

Ejecuta el siguiente comando

```bash
ssh-keygen -t rsa -b 4096 -C "tu@email.com"
```

- Una vez ejecutado el comando, se te pedirá que ingreses una ruta para guardar la llave, puedes dejar la ruta por defecto o bien, ingresar una ruta personalizada
- Se te pedirá que ingreses una contraseña, puedes dejarla en blanco o bien, ingresar una contraseña
- Una vez creada la llave, debes ejecutar el siguiente comando

```bash
eval "$(ssh-agent -s)"
```

- Ahora, debes agregar la llave a ssh

```bash
ssh-add ~/.ssh/id_rsa
```

1. Para obtener la llave, debes ejecutar el siguiente comando

---

### 2️⃣ Copiar la llave pública

```bash
cat ~/.ssh/id_rsa.pub
```

Copia todo el contenido.

---

### 3️⃣ Agregar la llave en GitHub

1. GitHub → Settings
2. SSH and GPG keys
3. New SSH key
4. Pegar la llave
5. Guardar

## 🍴 ¿Qué es un Fork?

Un **fork** es una **copia de un repositorio ajeno en tu cuenta de GitHub**.

Se usa cuando:

- No tienes permisos de escritura
- Quieres proponer cambios a un proyecto open source

### Flujo típico:

1. Hacer **Fork**
2. Clonar tu fork
3. Crear una rama
4. Hacer cambios
5. Enviar un **Pull Request**
