## 1. Imprimir en consola en Java

En Java, la salida por consola se realiza usando la clase `System.out`.

```java
System.out.println("Hola mundo");
System.out.print("Hola ");
System.out.print("mundo");
```

- `println` → imprime y hace **salto de línea**
- `print` → imprime sin salto de línea

---

## 2. Variables en Java

### Java es un lenguaje **fuertemente tipado**

A diferencia de lenguajes como **Python**, Java es **fuertemente tipado**, lo que significa que:

- Toda variable debe tener un **tipo de dato definido**
- El tipo no puede cambiar durante la ejecución
- Los errores de tipo se detectan en **tiempo de compilación**

👉 Ejemplo en Java (correcto):

```java
int edad = 25;
```

👉 En Python (no permitido en Java):

```python
edad = 25
edad = "veinticinco"
```

En Java esto causaría un error ❌

---

## 3. Declaración de variables en Java

La estructura general es:

```java
tipo nombreVariable = valor;
```

Ejemplos:

```java
int numero = 10;
double precio = 12.5;
String nombre = "Santiago";
boolean activo = true;
```

## 4. Tipos de datos en Java

### Tipos primitivos

| Tipo      | Descripción                 |
| --------- | --------------------------- |
| `int`     | Enteros                     |
| `double`  | Decimales                   |
| `float`   | Decimales (menor precisión) |
| `long`    | Enteros grandes             |
| `boolean` | true / false                |
| `char`    | Un solo carácter            |

### Tipo no primitivo

- `String` → cadenas de texto

---

## 5. Convenciones para nombrar variables

Java utiliza **camelCase**:

✔ Correcto:

```java
edadUsuario
totalCompra
nombreCompleto
```

❌ Incorrecto:

```java
EdadUsuario
total_compra
2edad
```

Reglas importantes:

- No iniciar con números
- No usar espacios
- Usar nombres descriptivos

## 6. Concatenación de cadenas de texto

Se usa el operador `+`:


## 9. Operadores aritméticos

## 12. Clase Scanner

Permite leer datos desde el teclado.

```java
import java.util.Scanner;

Scanner sc = new Scanner(System.in);
```

### Métodos más usados

```java
sc.nextInt();      // enteros
sc.nextDouble();  // decimales
sc.nextLine();    // texto
sc.nextBoolean(); // booleanos
```

Ejemplo:

```java
System.out.print("Ingrese su edad: ");
int edad = sc.nextInt();
```

## 16. Estructura `switch-case`

```java
switch (opcion) {
    case 1:
        System.out.println("Opción 1");
        break;
    case 2:
        System.out.println("Opción 2");
        break;
    default:
        System.out.println("Opción no válida");
}
```

---

## 17. Estructuras repetitivas

### `for`

Se usa cuando se conoce el número de repeticiones.

```java
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
```

---

### `while`

Evalúa la condición **antes** de ejecutar.

```java
int i = 0;
while (i < 5) {
    System.out.println(i);
    i++;
}
```

---

### `do-while`

Se ejecuta **al menos una vez**.

```java
int i = 0;
do {
    System.out.println(i);
    i++;
} while (i < 5);
```

---

## 18. Diferencias entre for, while y do-while

| Estructura | ¿Cuándo se evalúa la condición? | Uso típico                  |
| ---------- | ------------------------------- | --------------------------- |
| `for`      | Antes                           | Repeticiones contadas       |
| `while`    | Antes                           | Repeticiones indeterminadas |
| `do-while` | Después                         | Menús, validaciones         |
