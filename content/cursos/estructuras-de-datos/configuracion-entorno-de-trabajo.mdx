## Guía paso a paso para instalar el **JDK de Java 21 (Amazon Corretto)** en Windows 11

### 1. Descarga del JDK

- Ve a tu navegador y busca "Amazon Corretto 21"
- Entra en la página oficial de Amazon y busca la sección de **Windows**
- Descarga el archivo con extensión **.msi** (Windows x64 MSI) haciendo clic en el enlace de descarga

### 2. Instalación en el sistema

- Una vez descargado, ejecuta el archivo `.msi` con doble clic
- En el asistente de instalación (wizard), haz clic en **Next** (Siguiente).
- Mantén la configuración por defecto y haz clic en **Install** (Instalar).
- Si Windows te pide permisos de administrador, selecciona que **Sí** y espera a que finalice
- Haz clic en **Finish** (Finalizar).

### 3. Configuración de Variables de Entorno

Este paso es crucial para que puedas usar Java desde cualquier carpeta de tu computadora

- En el buscador de Windows, escribe **"variables"** y selecciona **"Editar las variables de entorno del sistema".**
- Haz clic en el botón **Variables de entorno.**
- **Verificar JAVA_HOME:** En "Variables del sistema", busca una llamada `JAVA_HOME`. El instalador suele crearla automáticamente apuntando a la ruta de instalación.
- **Configurar el Path:**
    1. Busca la variable **Path** en la lista de "Variables del sistema" y haz clic en **Editar**.
    2. Si ya existe una ruta al JDK, selecciónala y dale a **Editar**.
    3. Sustituye la ruta absoluta (hasta antes de la carpeta `bin`) por `%JAVA_HOME%\bin`. Esto asegura que el sistema siempre use la ubicación definida en `JAVA_HOME`.
- Haz clic en **Aceptar** en todas las ventanas abiertas.

### 4. Verificación final

- Abre una terminal (**PowerShell** o CMD).
- Escribe el comando: `java -version` y presiona Enter.
- Si la instalación fue exitosa, verás un mensaje indicando la versión de **OpenJDK 21** de Amazon Corretto

## ☕️ Java en VSCode

### 1. Instalación de VSCode

Puedes instalar VSCode en el siguiente enlace: [Descargar VSCode](https://code.visualstudio.com/)

### 2. Aprende a utilizar VSCode

[VISUAL STUDIO CODE: Tutorial para principiantes](https://www.youtube.com/watch?v=CxF3ykWP1H4)

[Free Visual Studio Code Tutorial - Visual Studio Code: Mejora tu velocidad para codificar](https://www.udemy.com/course/vscode-mejora-tu-velocidad-para-codificar/)

### 3. Instalar extensiones necesarias para Java

Abre VSCode y ve a **Extensions** (Ctrl + Shift + X)

Instala el paquete:

### 🔹 Extension Pack for Java (Microsoft)

Incluye:

- Language Support for Java
- Debugger for Java
- Java Test Runner
- Maven for Java
- Project Manager for Java

⚠️ Con esto ya tienes todo lo necesario para trabajar cómodamente.

---

### 4. Crear un proyecto Java en VSCode

### Usando el asistente

1. Presiona `Ctrl + Shift + P`
2. Escribe:
    
    ```
    Java: Create Java Project
    ```
    
3. Selecciona:
    - **No Build Tools** (para proyectos básicos)
4. Elige una carpeta
5. Escribe el nombre del proyecto

VSCode creará automáticamente la estructura:

```
ProyectoJava
 └── src
     └── App.java
```

---

### 5. Crear tu primera clase Java

Ejemplo de clase básica:

```java
public class App {
    public static void main(String[] args) {
        System.out.println("Hola mundo desde Java en VSCode");
    }
}
```

Guarda el archivo (`Ctrl + S`).

---

### 6. Ejecutar un programa Java

- Haz clic en **Run ▶️** sobre el método `main`
- El resultado aparecerá en la terminal integrada
